## Ice Cream Order Queue System
## Description
The Ice Cream Order Queue System is a C++ terminal-based program that manages an ice cream shop order line.
The system uses a **singly linked list as a FIFO queue**, allowing customers to be served in the order they place their orders.
## Features
* Take a new ice cream order
* Serve the next customer
* Display the order queue
* Search orders by flavor
* Sort orders by Order ID
* Clean up allocated memory when the program exits
## Data Structures & Algorithms
* **Singly Linked List** — used as a FIFO queue
* **Order Array** — used for searching and sorting
* **Bubble Sort** — used to sort orders by Order ID
* **Classes & Pointers** — used for object-oriented programming and memory management
## Classes
### IceCream
Stores:
* Order ID
* Flavor
* Quantity
### Node
Stores:
* Ice cream order
* Price
* Pointer to the next node
### LinkedList
Manages the queue using a head pointer.
